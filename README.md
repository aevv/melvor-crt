# CRT

A CRT effect for Melvor Idle 2: scanlines, a vignette and chromatic aberration towards
the edges, done by replacing the engine's blit shader.

A umitoo mod with no code: `mod.json` and one shader. It only takes effect on a mod
host that can replace engine shaders.

    umitoo run .        try it in the test profile
    umitoo publish .    send it to the registry
